# Regeln und Kriterien für das Referat

## Thema

- **Schwerpunkt:** eBPF als Linux-Netzwerkthema (`ebpf.io`).

## Umfang und Abgabe

- **Dauer:** 25 Minuten inklusive Diskussion und Fragen.
- **Abzugeben:** Folien sowie gegebenenfalls Code oder weitere Dateien, ein Handout und drei Fragen mit Antworten.
- **Handout:** Vor dem Vortrag allen zur Verfügung stellen. Es enthält eine textuelle Beschreibung der Inhalte und Referenzen.
- **Fragen:** Drei inhaltliche Fragen samt Antworten formulieren. Sie sollen das Wissen abdecken, das die vortragende Person vermitteln möchte. Bei der Prüfung wird eine Auswahl aus den Fragen verwendet.

## Gestaltung des Vortrags

- Der Vortrag kann Folien verwenden; alternativ kann Code oder ein Produkt präsentiert werden.
- Eine Präsentation, die anstelle von Folien Code oder ein Produkt zeigt, ist vorab mit der Lehrperson abzusprechen.

## Beurteilung

- **Vorbereitung, Inhalt, Präsentation, vollständige Referenzen und Pünktlichkeit:** werden berücksichtigt. Der Vortrag findet zum vereinbarten Termin statt. Bei Verhinderung wird entsprechend umgeplant; dabei wird die Zumutbarkeit im Sinne des Projektmanagements berücksichtigt.
- **Theoretischer Inhalt:** 40 %.
- **Praktischer Inhalt:** 60 %; dazu zählen beispielsweise Simulation, Laboraufbau sowie ein System mit passenden Features und Tests.
